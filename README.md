# 古代热搜辟谣局

> 古人上热搜，真相由你查。

把历史传闻放进现代社交平台，让用户从刷热搜开始，走进真正有依据的历史查证。

文化试验场 · 互动历史科普 Web 应用

- 项目仓库：<https://github.com/V-Giotto/ancient-hot-search-debunk>
- 项目网址：<https://ancient-hot-search.app.workbuddy.host/?sharecode=PSKI42CZSS>

## 01 这是一款什么作品？

《古代热搜辟谣局》是一款把历史知识做成“跨时空社交平台”的互动科普作品。古人也会发热搜，网友也会吃瓜；但当一条爆料越来越离谱，用户需要亲自判断真假，并用史料找到答案。

**核心创意：** 用社交媒体的吸引力，让玩家主动走进历史证据。

## 02 四个页面，让历史“刷”起来

| 页面 | 内容 | 作用 |
| --- | --- | --- |
| 热搜榜 | 热点排名、爆料标题、新闻式报道 | 用悬念吸引玩家点开历史 |
| 发现 | 像刷社区一样浏览图文、评论与讨论 | 让历史从不同视角被看见 |
| 好友 | 与历史人物进行文字聊天，可分享帖子 | 把严肃人物变成可交流的数字人 |
| 我的 | 收藏、查证进度、像素贴纸 | 让每次探索都有收获 |

## 03 用户怎么玩？从吃瓜到查证

1. **刷到热搜**：从“王莽穿越”等话题进入。
2. **围观与参与**：阅读评论、选择回应、找可疑措辞。
3. **判断与查证**：选择真/假，查看准确说法和来源。
4. **改写与分享**：改写流言，生成查证卡、收藏贴纸。

**体验重点——一假一真，都有依据：** 王莽铜卡尺不能证明穿越；战国冰鉴确实能借冰降温。

## 04 AI 亮点：能对话，也有证据边界

- **AI 历史人物数字人**：与李白、杜甫、苏轼等 13 位人物进行文字聊天，还能把帖子分享给他们讨论。每位人物都有独立的角色语气和时代约束。
- **智能史料问答**：用户在揭晓后继续提问；系统围绕该主题已整理的事实与来源生成解释，不让 AI 临场决定历史真假。

## 05 不只告诉答案，还留下收获

查证完成后，玩家可以做三选一严谨改写练习，把夸张传言改得更准确；再生成 PNG 查证卡，并在“我的”页面查看贴纸、进度和收藏。

- **表达能力**：从“我觉得”走向“我知道依据是什么”。
- **传播能力**：让正确说法以可保存、可转发的查证卡继续传播。
- **持续探索**：一主题一贴纸，回访同一主题也能重新挑战。

## 06 点赞收藏转发功能

帖子支持点赞、收藏、评论、转发；可转发给历史人物好友并在聊天中讨论。这一设计让历史知识不再局限于单向阅读，而是在浏览、互动、分享与讨论中自然传播。

## 07 创意和技术，怎样落到实处？

- **跨时空社交叙事**：热搜、发现、争论、好友聊天，共同组成可探索的古代互联网。
- **统一像素视觉**：原创像素封面、人物头像、荧绿点缀和深紫配色形成鲜明辨识度。
- **结构化内容体系**：历史题目（`data/topics`）、信息流（`data/feed`）、史料来源（`data/source-index.json`）与人物设定（`data/friends`）分层管理，方便持续扩展。
- **证据约束的 AI**：服务端固定判题 + 已审核资料范围 + 角色知识权限与输出校验。
- **工程实现**：Next.js / React / TypeScript Web 应用，响应式布局，包含自动化测试（Vitest）与真实浏览器交互回归（Playwright）。

## 本地运行

需要 Node.js（版本见 `package.json` 的 `engines.node`）和 npm。

```bash
npm ci
cp .env.example .env.local
npm run dev
```

打开 <http://localhost:3000>。不配置 AI Key 时，可浏览热搜榜、发现页和帖子，完成真假判断、揭晓与来源查看、改写练习并导出 PNG 查证卡；AI 追问与好友聊天会提示暂不可用。

如需开启 AI 功能，在 `.env.local` 中填写自己的 Key（只由服务端读取，切勿提交到 Git 或加 `NEXT_PUBLIC_` 前缀）：

```dotenv
AI_API_KEY=
AI_BASE_URL=https://api.deepseek.com
AI_MODEL=deepseek-flash
AI_TIMEOUT_MS=20000
```

常用命令：

| 命令 | 说明 |
| --- | --- |
| `npm run dev` | 开发服务 |
| `npm run build` / `npm start` | 生产构建与启动 |
| `npm run lint` / `npm run typecheck` | 代码检查与类型检查 |
| `npm test` | 单元测试（AI 调用全部 mock） |
| `npm run test:e2e` | 浏览器端到端回归（不调用真实 AI） |
