# 三分钟演示脚本

依据[任务书 10.1 与 10.4](任务书.md)。三分钟是内部排练方案，官方路演时长未知。固定案例为 H03（假）和 H06（真）。当前八题和来源均为 pending，只能展示开发预览，不能声称已经人工核验。

| 时间 | 操作与讲解 | 展示重点 |
| --- | --- | --- |
| 0:00–0:20 | 打开 `/trending`，扫过李杜、宋代送食、唐代辣椒、交子等标题。开场：“如果古人也会上热搜，你会相信哪一条？” | 现代社媒结构、原创封面、模拟热度、架空演绎标识 |
| 0:20–0:50 | 打开 H03，从当前页面前四条评论中朗读两条，再展开评论；指出账号发言都是现代创作。 | 角色、幽默与线索；封面不是史料 |
| 0:50–1:15 | 聚焦核心主张，选择“是假的”并提交，展示约 600ms 的“谣言退散”；展开史料依据。 | 假题反转、固定解释、可点开的来源；保留待审核提示 |
| 1:15–1:50 | 现场输入“唐朝人到底有没有辣味调料？”并发送。等待真实模型回答，指出来源链接与“AI 生成，可能有误”提示。备用问题：“唐人吃的胡椒和今天的辣椒是一回事吗？” | AI 只围绕事实卡解释，不能超出来源补写历史 |
| 1:50–2:15 | 选择 H03 改写 C，打开查证卡，下载 PNG 并确认文件。 | 从辨别信息到准确表达、可带走的 1200×675 查证卡 |
| 2:15–2:45 | 切换 `/discover`，打开 H06，选择“是真的”，展示“查证属实”。简述器具借冰块降温、使用范围须限定；如有时间展示现有来源。 | “看似离谱却是真的”的第二次反转；不把冰鉴说成电冰箱 |
| 2:45–3:00 | 收尾：“让历史因为一个梗被点开，因为一个证据被记住。真假由固定数据和人工审核流程负责，AI 负责围绕证据解释；当前资料仍待人工审核。” | 文化传播价值、AI 边界与真实审核进度 |

评论朗读以页面现有文本为准，不使用讲解者临时编造的“古人原话”。H06 正确改写为 A；不必重复全部互动，以免超时。实时 AI 等待时可先展示来源和改写，再返回查看结果。

## 演示前与容灾（10.4）

- 在正式排练前对 H03 主问题实测至少 5 次，记录状态、引用和延迟；本次七题 QA 不等于已完成该排练要求。备选问题也提前验证。注意每 IP 每分钟 10 次限流，不连续轰炸接口。
- 提前打开生产服务，确认安全注入密钥；当前 pending 内容只可用 `CONTENT_MODE=preview` 联调。正式演示前须由人工完成审核，再以 formal 验证，不通过切换模式伪造审核结果。
- 预先确认 H03/H06 的本机进度，使用独立演示浏览器配置保留一条首次体验路径；已回答时页面会显示“重温本条”。不在台上安装依赖或重建服务。
- 网络或模型异常：如实说明“实时 AI 当前网络不可用”，保留错误提示，转去演示预制解释、史料、改写、PNG；不要把预写文字或 mock 宣称为实时 AI。输入会保留，可以手动重试。
- 准备本地备用视频，播放时清楚标为“录制演示”。录像目前待团队录制，不能将截图或 Figma 原型冒充可运行作品。
- 内部建议按 1440×900 录制，并在 1920×1080 投影前核对字号、缩放与弹窗；这不是赛事官方分辨率要求。截图位于 `artifacts/stage-3/screenshots/`，不会自动进入 Git。
- 若官方另有时长或交付要求，由负责人取得原文后调整本脚本；官方规则仍未知。
