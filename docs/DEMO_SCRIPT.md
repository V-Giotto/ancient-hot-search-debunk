依据[任务书 10.1 与 10.4](任务书.md)。三分钟是内部排练方案，官方路演时长未知。固定案例为 H03（假）和 H06（真）。2026-10-30：Giotto 单人审核全部 12 题（6 真 6 假）与全部 28 条来源，全部通过；项目负责人于同日确认。未进行第二人抽查。当前题目与来源均为 reviewed，可用 formal 演示。

## 演示前与容灾（10.4）

- 在目标工作区完成构建后，先运行 `npm run check:port`，默认检查 3000；使用自定义端口时运行 `PORT=3999 npm run check:port`，随后 `CONTENT_MODE=preview PORT=3999 npm start`。也支持 `npm start -- --port 3999`。`npm start` 自动检查同一端口，占用即退出；先确认旧进程再停止，避免误连旧版本。
- 翻到 preview 页面页脚，核对版本为 `v0.14.0`，构建 ID 与 `.next/BUILD_ID` 完全相同；确认构建对应本次目标工作区。ID 标识构建，不等于 Git 提交哈希。formal 不显示该页脚，运行模式与 API 在服务运行时保持一致。
- 实测揭晓首屏“问问 AI”可直达追问区，标题不被吸顶头遮挡；409 文案为“本条内容审核中，暂不开放追问”，503 为“AI 未配置”，两者均检查“重试提问”和“返回揭晓”，返回后问题保留。配置检查不打印或录制密钥。
- 在正式排练前对 H03 主问题实测至少 5 次，记录状态、引用和延迟；本次七题 QA 不等于已完成该排练要求。备选问题也提前验证。注意每 IP 每分钟 10 次限流，不连续轰炸接口。
- 提前打开生产服务，确认安全注入密钥；当前 reviewed 内容可使用 `CONTENT_MODE=formal`。preview 仅为开发模式，不能通过切换模式改变审核结果。
- 预先确认 H03/H06 的本机进度，使用独立演示浏览器配置保留一条首次体验路径；已收集时显示“贴纸已收藏”，每次进入仍重新作答。不在台上安装依赖或重建服务。
- 网络或模型异常：如实说明“实时 AI 当前网络不可用”，保留错误提示，转去演示预制解释、史料、改写、PNG；不要把预写文字或 mock 宣称为实时 AI。输入会保留，可以手动重试。
- 准备本地备用视频，播放时清楚标为“录制演示”。录像目前待团队录制，不能将截图或 Figma 原型冒充可运行作品。
- 内部建议按 1440×900 录制，并在 1920×1080 投影前核对字号、缩放与弹窗；这不是赛事官方分辨率要求。截图位于 `artifacts/stage-3/screenshots/`，不会自动进入 Git。
- 若官方另有时长或交付要求，由负责人取得原文后调整本脚本；官方规则仍未知。
