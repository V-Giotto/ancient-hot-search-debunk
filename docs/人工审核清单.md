# 人工审核清单

供项目负责人组织内容审核、分配复核与登记结果使用。本清单只汇总 `data/topics/h01.json` 至 `h08.json` 的命题、揭晓、事实卡和 [内容审核记录](CONTENT_REVIEW.md)，来源标题与 URL 取自 `data/source-index.json`；不引入额外史实或来源。

当前8条题目与19条来源全部为 `pending`，无审核人或审核日期。下列“真／假”是数据预设结论，待人工审核；阶段4新增的四条第二来源仅由 AI 助手于 2026-10-29 联网打开、确认页面可访问且含所引原文，尚未经人工核对，不代表整题通过审核。准确表述逐字取自 `reveal.correctedClaim`，正确改写逐字取自唯一 `isBest: true` 选项。

每题均须审封面、帖子、8条评论与四种角色，确认虚构账号和模拟互动有明确标识。原创图的“艺术创作·非史料”与 [素材登记](ASSET_LICENSES.md) 需一致；图片和段子不能充当史料，评论不得提前揭晓答案。以下列出逐题的重点。
