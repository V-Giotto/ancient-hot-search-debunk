### H13（已审核并入库）｜兵马俑原本就是灰色的吗？
- 已审命题：秦兵马俑制作之初就只有灰色（不施彩绘）。
- 已审结论：假。兵马俑原有彩绘（生漆打底再敷彩），埋藏中老化剥落，出土时残存彩绘又因失水迅速起翘脱落；今天多见灰色陶胎。
- 已审来源（reviewed · Giotto · 2026-10-30T09:53:00-07:00）：
  1. 秦始皇帝陵博物院《秦兵马俑彩绘保护技术取得突破》（2020-04-23）https://bmy.com.cn/news/news/2060.html ——“尤其是作为陶俑雕塑补充的彩绘……由于生漆底层对外界环境的变化高度敏感，因此，兵马俑出土后很快发生起翘和卷曲，造成整个彩绘层脱落”；“秦兵马俑彩绘是由底层生漆和颜料层构成的”；“在有确切出土地点和年代的秦俑上，首次发现了……紫色硅酸铜钡颜料”。核查日期 2026-10-30。
  2. 秦始皇帝陵博物院《40年来秦俑考古发掘与科技保护》https://bmy.com.cn/news/news/1618.html ——“色彩斑驳的秦兵马俑”“底层（生漆）对失水非常敏感，在干燥过程中底层剧烈收缩，引起底层起翘卷曲，造成整个彩绘层脱离陶体”；实验“1分钟后，生漆层的两端明显起翘，4分钟后，大部分起翘”。核查日期 2026-10-30。
  3. 新华网《一个你未曾见过的彩色世界——还原秦始皇帝陵兵马俑的“中国色彩”》（2017-09-16）http://www.xinhuanet.com/politics/2017-09/16/c_1121673179.htm ——引秦陵博物院研究员夏寅：“每个兵马俑其实都有颜色……出土后１５秒就开始变化，４分钟内就完全脱水、起翘、剥落”；袁仲一列朱红、枣红、紫红、粉红、深绿、粉绿、粉紫、粉蓝、中黄、桔黄、黑、白、赭等十几种颜色。核查日期 2026-10-30。
  4. 人民网《“我们是兵马俑的专科医生”》（2018-10-25）http://culture.people.com.cn/n1/2018/1025/c1013-30360952.html ——修复专家兰德省：“兵马俑出土几分钟就失去颜色，这种说法曾非常流行……经过各种摧残，兵马俑出土时本身残存的色彩状况就不太好”；“彩绘是制作时最后一个步骤，俑上涂层生漆作底，再在上面敷彩”。核查日期 2026-10-30。
- 限制与注意：①来源 3 与 4 对“出土几分钟褪色”的强调程度不同——揭晓应写“埋藏老化 + 出土后失水剥落”两重原因，不写成“一出土全部瞬间褪色”。②“十几种颜色”是整体统计，不可说每尊颜色相同或每尊都有十几色（来源 3 指出将军俑用色多、士兵俑局部简单描绘）。③现代复原彩图不是单件文物颜色的直接证据。④“中国紫”只写“在有确切出土地点和年代的秦俑上首次发现”，不扩写为世界最早。
