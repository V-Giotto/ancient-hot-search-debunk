# AI 使用说明

## 研发与原创素材

本项目使用 **Codex gpt-6.1-sol** 辅助编写、修改代码、测试和文档。封面为 AI 直接编写的原创 SVG 代码，并非使用外部照片、真实品牌标志或馆藏图；八张封面的创意、提示与用途登记见 [ASSET_LICENSES.md](ASSET_LICENSES.md)。按 2026-10-29 项目负责人决定，SVG 已移除可见虚构/非史料角标；素材仍为原创非史料，属性记录在素材文档中，不提供器物精确复原或真实人物肖像的证明。

热搜、架空账号、评论及解释文案的初稿由 AI 辅助生成。角色发言、互动数字和跨时空社交情景均为现代演绎；AI 初稿及代码生成不代表史料已经人工确认。当前全部题目与来源仍 pending，尚不能声称人工审核完成。

## 运行时 AI

揭晓后自由追问调用服务端 DeepSeek 兼容接口，默认 `AI_BASE_URL=https://api.deepseek.com`、`AI_MODEL=deepseek-flash`。密钥只从服务端 `AI_API_KEY` 读取；模型可按部署环境替换为兼容接口。没有密钥时明确提示未配置，浏览、判断、固定解释、改写和 PNG 导出仍可用。

每次调用只使用当前题目的服务端事实卡、限制与准许来源，不接受客户端自带的事实。用户问题与历史作为不可信数据隔离；引用 ID 经过服务端白名单过滤和去重。未知 ID（如 `made-up-999`）不能展示，无有效引用时 grounded 为 false。`grounded` 只表示模型声明及引用完整性，不证明逐句语义核验。

preview 允许 pending 资料用于联调，回答须标待审核；formal 仅允许 reviewed 话题及 reviewed 来源，rejected 始终排除。资料不足、伪造私信、捏造史书或问题超出证据范围时应承认不足或拒绝，不凭记忆补充年代、价格、原文或出处。页面保留“AI 生成，可能有误，以史料为准”提示。阶段 3 的真实响应记录见 [QA_REPORT.md](QA_REPORT.md)。

## 人工把关与史实责任

**史实真假不由运行时 AI 判定。** `/api/verdict` 从仓库固定 `isTrue` 数据判题；AI 不修改真值、来源或审核状态。当前 pending 真值只是开发数据，正式发布前必须由人工完成任务书 5.3 的审核流程。

编辑先界定可核对的单一主张，审核人打开原始文献或可靠机构资料，核对具体支持点、出处与限制；第二人抽查后才可填写审核人、日期并标记 reviewed。有争议或来源失效时退回 pending，不能因模型回答流畅或测试通过而签字。人工还需审查幽默表达、原创插画和现代类比，避免将演绎当作古人原话或将个案说成普及。本次不改变任何审核状态。

问题和对话只用于当次模型请求及页面内存展示，不写入本机进度；应用不记录完整问题、提供商原文或密钥。外部模型服务会接收请求中的问题与事实上下文；无真实账号或第三方统计模块。
